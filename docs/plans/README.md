## Соглашения (общие для всех планов)

- **Структура репозитория** — монорепо, npm workspaces:
  ```
  clever-vibe/
    package.json      — workspaces: ["server", "web"]
    server/           — Fastify + Prisma + PostgreSQL (TypeScript)
    web/              — Vue 3 + Vite + PrimeVue + Tailwind (TypeScript)
    docs/
  ```
- **Язык кода** — TypeScript и на бэке, и на фронте. Node 22 LTS, npm.
- **Тесты** — Vitest в обоих пакетах. TDD для чистой логики (генерация логина/пароля, матрица прав, агрегаты, окно редактирования, черновик, сводка). Роуты Fastify тестируются через `app.inject()` с фейковым Prisma, который передаётся в `buildApp({ prisma })`. Разметка и вёрстка проверяются вручную по шагам «Проверка в браузере».
- **Коммиты** — Conventional Commits (`feat:`, `fix:`, `chore:`, `test:`), после каждой задачи. Работа в ветке `develop` (репозиторий приватный, PR-процесс не обязателен — команда из одного исполнителя).
- **Иконки** — только PrimeIcons (соответствия Phosphor → PrimeIcons в разделе 5 ТЗ). **Шрифт** — Inter локально через `@fontsource/inter`, не CDN.
- **Все выводимые средние** округляются до 1 знака: `round1()` — единая функция.
- **API** — префикс `/api`, JSON. Аутентификация каждого запроса — заголовок `Authorization: Basic base64(login:password)` (сессий и JWT нет по ТЗ; связка хранится в `localStorage`, бэкенд проверяет права на каждом запросе).
- **Ключи localStorage**: `aiTrackerAuth` (связка логин/пароль), `aiTrackerTheme` (тема), `aiTrackerDraft` (черновик формы), `aiTrackerLastTool` (последний инструмент).

## Принятые допущения (не описаны в ТЗ явно)

1. **Транспорт учётных данных** — HTTP Basic на каждом запросе (минимальный механизм, удовлетворяющий «без сессий и JWT, проверка прав на бэкенде»).
2. **Промоут кастомного подхода** проставляет `approachId` записям с совпадающим (нормализованным) текстом, `customApproachText` при этом сохраняется для истории и CSV. Так записи начинают учитываться в агрегатах дашборда. Признак «В справочнике» — по полю `Approach.promotedFromText`.
3. **Экспорт CSV** не включает записи с `deletedAt` (как и агрегаты).
4. **Виджет 4 «разброс между участниками»** строится по средним `usefulness` участников (в ТЗ шкала не уточнена).
5. **Охват `n/4`** — знаменатель равен числу активных участников с правом внесения записей (роли `dev`, `lead`, `admin`).
6. **Справочник инструментов** сидируется плейсхолдерным списком — **уточнить утверждённый список у заказчика до развёртывания** (`server/prisma/seedData.ts`).
7. Интерфейс целиком на русском языке, i18n не закладывается.
